# P09 production ownership and evidence

This live ledger groups the frozen `grammar/php.y` productions by implementation responsibility. The [frozen production inventory](../compatibility/grammar.jsonl) is unchanged. List/non-empty/optional productions below are implemented by bounded loops and option handling in their listed owner; they do not require separate Rust functions. Positive evidence is in the [60-probe input catalog](../../tools/declarations/inputs.json), with exact reference observations in `tests/fixtures/declarations/declarations.json`, and the 101 P09-owned upstream structure channels. Negative evidence combines those reference validation fixtures with `invalid_declaration_productions_are_never_clean` and recovery tests in [declarations.rs](../../tests/declarations.rs).

The mixed frozen `top_statement` production also contains PHP 8.5 constant attributes; this branch is explicitly rejected. Shared `argument_list`, expression/default parsing, callable bodies, comments/no-ops, statement lists and terminators remain owned by P07/P08 modules and their tests. No future pipe/void-cast/partial-application production is promoted by P09. Metadata and exact diagnostic wording are separate P10/P11 obligations.
