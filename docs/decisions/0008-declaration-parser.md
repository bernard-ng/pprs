# P09 namespaces, declarations, members and types

Accepted 2026-10-17. The library now parses the in-scope declaration grammar through PHP 8.4. Version/source fidelity remains P10 and broad malformed-file/diagnostic equivalence remains P11. This is a parser, not a PHP compiler or name resolver. No runtime crate or product binary was added.

## Representation and grammar

Declarations use owned typed payloads in `ast::declarations`: namespaces/imports, constants, class-like declarations, methods, properties, traits/adaptations, enums/cases, attributes and hooks. `Modifiers` preserves explicit bits, including invalid combinations retained during recovery; implicit public and `var` stay zero as in the reference. Class-like kind, namespace style, grouped-import prefix, import category, abstract method body, and abstract/block/expression hook body remain explicit. Hook parentheses are preserved separately from an empty parameter list.

P08's `Signature`, `Parameter` and `Type` are reused. Parameters and callables now retain attribute groups; promoted parameters add modifiers and hooks. The shared type grammar handles property and typed-constant declarations, DNF intersections and target-sensitive builtin names. Enum backing types follow the reference's single-type grammar, without adding runtime restrictions. Anonymous construction owns both a class declaration and constructor arguments; traversal puts attributes and arguments before inheritance and members in source order. Class payloads are boxed to keep recursive parser transfers small.

The parser handles braced and semicolon namespaces, aliases, function/constant imports, grouped and mixed imports; classes, interfaces, traits and adaptations; global/class constants; methods and properties; attributes; enums; readonly declarations; promotion; PHP 8.4 hooks and asymmetric visibility. Semi-reserved member/stub names follow the reference. Names are syntactic and unresolved. Namespace grouping is performed at file completion so semicolon namespaces contain their subsequent statements while halt remains outside; grouped ranges extend through their last child. Malformed nested semicolon namespaces may retain an absent unnormalized body. This implements the semantic grouping originally listed in P10; full metadata fidelity is still audited there.

Validation follows reference parser checks: conflicting/duplicate modifiers, special class names in names/inheritance/aliases, static lifecycle methods, readonly methods, invalid class-constant flags, namespace placement/style/nesting/outside code, empty or multi-property hooks, unknown hook names, getter parameter lists, and hook modifiers. Compiler-only constraints are intentionally absent: trait names, enum backing-type legality, duplicate enum cases, property legality in interfaces, and many promotion/type restrictions may be accepted by the reference. Attributes and readonly spellings use the existing target-aware lexer. As agreed in P00, PHP 8.5 global-constant attributes and final promoted parameters produce unsupported-syntax errors; their frozen fixtures remain deferred. Earlier target selection does not reject every newer syntax inside the supported 7.0–8.4 ceiling.

## Recovery, ownership and budgets

Class/member, trait-adaptation and property-hook lists have local recovery boundaries. A damaged trait adaptation no longer loses subsequent members. A missing hook-list closing brace can be inserted before an unambiguous following member; this recognition uses the existing three-token cursor window. Ambiguous or more extensively damaged headers still use bounded synchronization, with broad recovery parity left to P11. Missing declaration terminators preserve following declaration anchors. Unbraced conditional/loop bodies diagnose declarations requiring a statement list.

All auxiliary nodes participate in node/depth limits and iterative traversal. Namespace grouping is followed by a depth validation because it adds AST nesting; an over-budget result aborts with an empty retained program rather than exposing a tree exceeding its limit. Repeated modifier and synchronization scans are bounded by tokens/diagnostics. The parser retains P07's conservative native-stack cap of 128. A deep-block regression exposed larger declaration dispatch frames; standalone block bodies now charge grammar depth consistently with other scoped bodies. Thousand-level blocks, namespaces, nested classes/methods, anonymous initializers, attributes and hooks now abort at limits. All byte prefixes and small budgets of the 60 probes run through shared source/token/node/metadata invariants.

Five exact upstream differences are deliberate recovery policies, recorded under `tests/fixtures/differences/p09-recovery-*.json`:

- Three invalid class/interface names (`static`, or reserved `ReadOnly`) discard the damaged declaration through its braces. The reference exposes the braces as a standalone block. Subsequent valid statements are retained.
- A grouped import missing its namespace separator is discarded through its braced suffix. The reference retains a simple import and reinterprets the suffix as ordinary statements.
- A leading separator inside a group is diagnosed and the recovered import item is retained with a normalized name. The reference drops the import and returns a fully qualified constant expression from the suffix.

None can pass strict conversion. Each alternate AST/status is pinned independently, and the comparison gate still rejects unrelated differences. No passing channel was demoted or frozen observation changed.

## Evidence and remaining work

P09 adds **96 exact upstream structure/status channels and five intentional differences**, plus **60 focused observations**: 30 versioned type/modifier, namespace/import and attribute cases across all ten targets, and 30 focused declaration/validation cases. Positive/negative production ownership is documented in the [declaration ledger](../implementation/declarations.md). Tests additionally cover local recovery, strict rejection, source-order traversal, grouping ranges, deep nesting, every probe truncation, small budgets, 256 arbitrary declaration-token sequences and the minimized cursor-window regression. The fuzz target adds class/hook/trait/import/attribute/anonymous-class entry states; compilation is checked, not an instrumented campaign.

Combined structure coverage is **214 passing channels and 15 explicit differences**. No P07/P08/P09 structure channel remains pending. All 300 complete cases remain pending overall until metadata and full diagnostics are promoted; 71 structure obligations still belong to P10/P11. All 190 in-scope node-family mappings now exist, with three deferred families. `slice` remains the ledger status because an implemented AST family does not imply complete positions, comments, diagnostics or every version edge case.
