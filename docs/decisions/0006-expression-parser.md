# P07 expression parser and first public parsing slice

Accepted 2026-10-16. The library now parses the expression/file subset using the production lexer and the frozen PHP-Parser grammar. Functions, closures, arrow functions and control flow remain P08; declarations, namespaces and anonymous classes remain P09. Unsupported syntax emits an error and cannot produce strict success.

## Public contract

`parse(input, options)` copies caller bytes after checking the input budget. `parse_source(source, options)` reuses shared source storage. Both return `Result<ParseResult, InputTooLarge>`; a result owns source, lossless tokens, diagnostics and a complete or partial `Program`. `parse_strict` returns `Result<ParsedFile, StrictError>`: `Input` reports preflight rejection, while `Parse` retains the entire non-clean result. This refines the draft single-error signature to preserve P06's input-limit-before-allocation guarantee. Strict means no recovery/error/resource stop, not PHP compiler or historical-version validation.

Supported statements are empty files, inline HTML, comments/no-ops, expression statements, echo/short echo, return, blocks and outermost `__halt_compiler`. Expressions cover literals and interpolation; names and unevaluated magic constants; variables; arrays and destructuring; unary, binary, assignment, reference, ternary and coalesce operators; calls, named/reference/unpacked arguments and first-class placeholders; dimensions and dynamic/static/nullsafe members; construction and cloning; casts, include/require, eval, print, isset/empty, exit/die, throw, match and yield forms. Callables and anonymous-class bodies remain explicitly unsupported.

The private parser uses recursive descent and Pratt binding powers, with no general backtracking. `operators.rs` records the binding table, including PHP 7 versus PHP 8 concatenation. Assignment targets and argument/reference contexts have explicit grammar checks. Reference acceptance is not equivalent to writable PHP at execution time: the frozen parser accepts examples such as `f() = 1`, nullsafe assignment and scalar elements in destructuring. PPRS follows that grammar rather than adding a compiler pass. Complex clone and exit argument lists use function-call nodes as in the reference; ordinary `clone($x)` remains a unary operation. No PHP code or magic constant is evaluated.

Existing Logos scanning, literal utilities, byte strings and error types are reused. There are no new runtime dependencies. Recursive parser calls transfer boxed expressions, limiting native stack frames; owned child boxes also prevent expensive subtree copies. The AST remains typed and exposes source/token metadata. Auxiliary argument, item, match-arm and interpolation text nodes have their own metadata. `visit::walk` is an iterative preorder iterator that visits these nodes in grammar/source order and reports one-based depth. Grouping updates origin ranges without inventing a grouping AST variant. Exact reference metadata/comment attachment remains P10, not a P07 parity claim.

## Recovery and budgets

Missing operands can create `ExprKind::Error` without consuming a delimiter. Missing terminators are inserted at unambiguous expression/statement boundaries; other failures synchronize over balanced delimiters to a terminator, block boundary or echo/return/HTML anchor. Progress guards prevent retrying the same token. Blocks restore scope even when parsing fails. Recovery across later-phase syntax is best effort; complete unsupported constructs are not guaranteed to preserve nested statements. P08/P09 add their own recovery boundaries, and P11 owns broad malformed-file equivalence and diagnostic wording.

Invalid Unicode escapes retain an expression error node and continue parsing. The reference aborts its entire tree in these cases. All eight affected P02 fixtures have exact alternate structure/status snapshots and reasons in the live coverage ledger. Invalid octals retain the reference's zero value with an error; malformed doc-string indentation strips the available prefix while diagnosing the failure. No invalid literal is silently accepted as clean. These choices preserve subsequent valid statements and always fail strict conversion.

Input, token, node, diagnostic and depth budgets apply cumulatively. Root and auxiliary AST nodes count toward the node budget, including constructed nodes later discarded during recovery. AST depth is checked with the iterative traversal independently of recursive grammar depth; grammar depth is conservatively counted and includes the root. The effective parser depth is `min(configured_depth, 128)` even if the caller requests more, protecting native stack use. This is provisional until P12. Partial retained trees remain within configured node/depth limits. A terminal resource diagnostic aborts parsing, and the cursor retains the unscanned suffix plus EOF without further scanning. The reserved diagnostic slot includes lexer and parser errors together. A regression test covers a token-budget stop during block recovery; stopped cursors are never queried again.

Halt handling uses P06's lazy, syntax-and-scope-validated boundary before scanning the payload. Valid outermost syntax preserves arbitrary trailing bytes, including invalid PHP and non-UTF-8. Malformed or nested halt syntax does not switch to raw-tail mode. Standalone lexing keeps its four documented differences; parser-level halt probes verify the authorized path separately.

## Evidence and phase accounting

- 133 dedicated, reproducible reference observations include 100 precedence cases across all ten targets, every P07 operator family, expression contexts, interpolation, file boundaries, blocks and halt tails. These compare exact normalized trees and completion status offline.
- The P02 structure channel now has 69 exact matches and eight explicit Unicode recovery differences owned by P07. No P07 structure channel remains pending.
- 32 initially P07-assigned complete files also contain functions/control flow (eight files, P08) or declarations/anonymous classes (24 files, P09). Only their live structure ownership changed, with reasons. Frozen P00 inventories and P02 observations are unchanged. Focused expression probes cover the expression portions of these mixed files.
- Token coverage remains 296 exact streams plus four standalone-halt differences. All 300 complete parser cases remain pending overall because positions/comments and diagnostic channels are not promoted. The node ledger's `slice` status means P07 construction exists, not full family compatibility.
- Tests check caller-independent ownership, strict failures, traversal order, malformed-expression recovery, every truncation of the focused non-precedence probes, all 300 core files for invariants, 512 arbitrary-byte/small-budget cases, and deep parentheses/operators/arrays/calls/matches/interpolation/blocks. Three failures found during development (native stack size, recovery after resource abort and the trailing-comment depth check) have deterministic regressions.
- `parse_bytes` adds a bounded libFuzzer target alongside `lex_bytes`. Compilation is checked; an instrumented campaign remains P12.
